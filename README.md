
# Calculadora Web

Projeto de uma calculadora web desenvolvida
com HTML, CSS e JavaScript.

## Funcionalidades

- Adição
- Subtração
- Multiplicação
- Divisão
- Cálculo de porcentagem
- Alteração do sinal do número
- Limpeza do visor
- Tratamento de divisão por zero

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Node.js para testes automatizados
- Git e GitHub
- GitHub Actions

## Como executar

1. Clone este repositório.
2. Abra a pasta `src`.
3. Abra o arquivo `index.html` no navegador.

Também é possível usar a extensão Live Server no VS Code.

## Testes automatizados

Os testes verificam as operações matemáticas e situações
de erro utilizando Node.js.

## GitHub Actions

O GitHub Actions executa os testes automaticamente
quando há um push ou Pull Request.

## Objetivo acadêmico

Demonstrar código-fonte, documentação, controle de versão,
testes automatizados e integração contínua.
